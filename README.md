# Equation Station SA

Equation Station SA is a South African mathematics learning platform founded by Chris Khomo. It combines CAPS-aligned explanations, worked examples and digital learning experiences designed to make difficult concepts easier to understand.

This repository contains an early web prototype. The current platform is maintained separately.

## Portfolio highlights

- CAPS-aligned Grade 12 mathematics content
- Topic-based learning journeys
- Responsive web design
- Video lesson integration
- Clear links from concepts to guided support
